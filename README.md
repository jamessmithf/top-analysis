# Top Analysis — Аналіз навантаження системи через `top`

Збір даних про завантаженість CPU і пам'яті за допомогою `top`, статистичний аналіз і генерація PDF-звіту з графіками.

## Що демонструє цей проєкт

- Парсинг та аналіз виводу утиліти `top`
- Візуалізація CPU/пам'яті у часі та розподілу навантаження між процесами
- Генерація анотованих графіків і PDF-звіту через `matplotlib` і `reportlab`

## Як запустити

### Збір даних

Запусти `top` у batch-режимі і збережи вивід у файл:

```bash
top -b -n 60 -d 1 > top_output.txt
```

- `-b` — batch mode (без інтерактивного TUI)
- `-n 60` — 60 ітерацій
- `-d 1` — інтервал 1 секунда
